# gator-product

Shared **product briefs** for Gator. Markdown in git. Brian and Bojan write here (via Cursor Agent). Mihailo and Wei read here when they need product context.

This is not the app, not prototypes, and not working notes.

## Folders

- `product/` — source of truth. One file per topic. Rewrite the file when the product changes.
- `decisions/` — short dated notes: we chose X because Y.

## How to add or change a brief

Open this repo in Cursor. Tell the Agent the outcome (what changed, what we decided). Read the preview. Ask it to commit and push to `main`.

## Who clones this

Everyone on the team. An Agent in `gator-frontend` cannot see these files unless this repo is also open — `@` a brief when that matters.
